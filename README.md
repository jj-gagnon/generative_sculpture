# Version 8


### Description
In this version I figured out how to more easily get text labels in ThreeJS.
Fortunately there is a library for sprite based text called three-spritetext.  (https://github.com/vasturiano/three-spritetext)

I added labels for the ID of each piece, as well as the Y and Z axis rotation.
