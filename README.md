# Step 10: Adding labels for angles and piece IDs


### Features

1. In this version I figured out how to more easily get text labels in ThreeJS, because natively it does not handle text very cleanly.<br>
Fortunately there is a library for sprite based text called three-spritetext. (https://github.com/vasturiano/three-spritetext)<br>
I added labels for the ID of each piece, as well as the Y and Z axis rotation. 

2. Made a lil-gui button to toggle viewing the labels or not. 

3. Made the labels update their values after the sliders have changed.
